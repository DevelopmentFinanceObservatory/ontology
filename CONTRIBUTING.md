# Contributing

Contributions are welcome, from questions and bug reports to code.

This repository holds the compiler, not the concepts. The ontology is written and
maintained on the [DFO wiki](https://developmentfinance.wikibase.cloud), so a change to
a concept starts as an issue here rather than a pull request.

## Questions and issues

Questions about the data are best raised on the website, where the team can triage them.
Issues here work best for a specific problem in the ontology, the compiler or its docs.
When an issue is about a concept, link its page on the wiki.

| If you want to…                                                        | Raise it at                                                                                        |
| ---------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| report a figure that looks wrong, or ask how a source is modelled      | the feedback form on the [DFO website](https://developmentfinance.org)                             |
| request a new source or dataset                                        | "Submit Request" on the [roadmap](https://developmentfinance.org/data/roadmap)                     |
| report a problem with a concept, property or code list in the ontology | an issue in this repository                                                                        |
| report a bug in the compiler or an error in these docs                 | an issue in this repository                                                                        |
| report a bug or failing step in a pipeline                             | an issue in the [pipelines repository](https://github.com/DevelopmentFinanceObservatory/pipelines) |
| improve an agent skill                                                 | an issue in the [skills repository](https://github.com/DevelopmentFinanceObservatory/skills)       |

## Contributing code

Open an issue before submitting a pull request, so the change can be discussed before
you make it.

Set up the project and run the tests and checks as described in the
[README](README.md). Each pull request addresses a single issue.

Commit messages and pull request titles follow
[Conventional Commits](https://www.conventionalcommits.org/).
